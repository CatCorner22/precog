# Precog

AI-assisted Lean + Internal Controls coach for small dental practices.

## What it does

- **Matrix process layers** — Surface Reality, Process, Knowledge/Tribal, Control & Governance, Source/Architecture, Continuity/Exit
- **Knowledge continuity map** — who holds critical knowledge, SPOF detection
- **Precog scenarios** — statistically grounded timelines with 95% confidence ranges, financial impact, staff composition modifiers, and crime/fraud base rates
- **Segregation of duties** — COSO-aligned conflicts, compensating controls, residual risk language

## Stack

React 19 · TanStack Start · Vite · Tailwind v4 · Recharts · Better Auth

## Develop

```bash
npm install
npm run dev   # 0.0.0.0:8080
```
